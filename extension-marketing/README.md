# EduCRM Marketing — розширення для робочої CRM

Переносить список клієнтів маркетингового заходу у Відкритий захід EduCRM.

1. У робочій CRM відкрийте **Маркетинг → Заходи** і вікно **«Список клієнтів»** потрібного заходу.
2. Унизу екрана з'явиться плашка з назвою заходу і кількістю клієнтів → **«Перенести»**.
3. Якщо у Відкритому заході вже є список — розширення попросить підтвердити заміну.
4. Старий список і назва очищаються; записуються нова назва і всі клієнти
   (ім'я, телефон, посилання на картку CRM). Дублікати за номером пропускаються.
5. **«Повернути»** — відновлює попередній список (копія зберігається в розширенні).

## Встановлення / оновлення
Завантажте архів на сторінці EduCRM **«Налаштування → Розширення»**, розпакуйте,
відкрийте `chrome://extensions`, увімкніть «Режим розробника» →
«Завантажити розпаковане» → виберіть папку з `manifest.json`.

`shared.js` — копія з основного розширення (`extension/shared.js`).

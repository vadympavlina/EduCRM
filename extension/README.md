# EduCRM — розширення для робочої CRM

Що вміє:
- На картці клієнта в `crm.itstep.org` у правому нижньому куті з'являється маленька
  кругла кнопка EduCRM. Клік — відкриває EduCRM (вже відкриту вкладку або нову)
  з діалогом нового заняття: ім'я, телефон і посилання на картку CRM уже заповнені.
- Зелена крапка на кнопці — у клієнта вже є майбутнє заняття. При наведенні видно,
  коли саме, і є перехід у картку клієнта в EduCRM. Хрестик ховає кнопку на цій картці.
- Номер шукається в будь-якому форматі і за всіма телефонами клієнта.
- Кнопка розширення на панелі браузера: те саме з вибором основного телефону.

## Встановлення / оновлення (Chrome, Edge, Brave)
1. Завантажте архів на сторінці EduCRM «Налаштування → Розширення» (або папку `extension`) (або розпакуйте `educrm-extension.zip`).
2. Відкрийте `chrome://extensions` і ввімкніть **Режим розробника** (праворуч угорі).
3. Якщо стара версія вже стоїть — видаліть її.
4. **Завантажити розпаковане** → виберіть папку з `manifest.json`.

Дані про заняття беруться з гілки `lookup` бази EduCRM — її оновлює сама EduCRM
при кожній зміні заняття і раз на день перебудовує повністю (минулі заняття зникають).

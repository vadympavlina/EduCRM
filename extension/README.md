# EduCRM — розширення для робочої CRM

Що вміє:
- На картці клієнта в `crm.itstep.org` показує найближче заняття з EduCRM
  (індивідуальне або групове) — за будь-яким номером клієнта і в будь-якому форматі.
  Через 12 секунд картка згортається в маленьку «пігулку» справа вгорі.
- Кнопка розширення: дані клієнта, вибір основного телефону, чи є заняття в EduCRM,
  «Записати на заняття» (відкриває EduCRM із заповненим діалогом) і перехід у картку клієнта.

## Встановлення / оновлення (Chrome, Edge, Brave)
1. Завантажте папку `extension` (або розпакуйте `educrm-extension.zip`).
2. Відкрийте `chrome://extensions` і ввімкніть **Режим розробника** (праворуч угорі).
3. Якщо стара версія вже стоїть — видаліть її.
4. **Завантажити розпаковане** → виберіть папку з `manifest.json`.

Дані про заняття беруться з гілки `lookup` бази EduCRM — її оновлює сама EduCRM
при кожній зміні заняття і раз на день перебудовує повністю (минулі заняття зникають).
